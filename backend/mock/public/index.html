0 у глибині історії — брати значення зі стенду. Блокування відкликає токен: застосунок на наступному запиті отримає 401 і вийде на екран входу, а після розблокування потрібен новий код прив'язки.

—

Код одноразовий: після прив'язки він гаситься. Генерація нового коду відв'язує пристрій (токен відкликається).

У браузері (npm run dev) камери немає, тож прив'язатись скануванням не можна: скопіюй другу кнопку й встав у консоль вкладки з додатком — вона обміняє код на токен і перезавантажить сторінку.

Порожній список = без обмеження (пристрій бачить усе).
